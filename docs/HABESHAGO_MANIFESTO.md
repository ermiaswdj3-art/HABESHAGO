# HABESHAGO Manifesto

Our mission is to build Ethiopia's most trusted mobility platform.

Every feature we build must improve at least one of these principles:

- Simple
- Fast
- Reliable
- Transparent
- Safe
- Consistent
- Context-Aware

We do not add features because they are fashionable.

We add features because they make HABESHAGO better for passengers, drivers, operators, and Ethiopia.

Every commit should leave HABESHAGO better than yesterday.

The interface should remember what the human shouldn't have to.

Build once.
Reuse everywhere.

Quality before quantity.

Architecture before shortcuts.

Trust is our greatest feature.
